Welcome to the Student Locating System for Centerville Jr. Documentation. This system is intended for use in the Math tutoring department of Centerville Jr. High. The current Document and it's related pages describe what this system is and how to use it. For ease of use, it is recommended to view this documentation in [Obsidian](https://obsidian.md/) or a similar Markdown viewer.

Currently, as it stands, this system comprises of a [[What is a Database|database]] put in the program *MySQL*. MySQL is a  program that is designed to store and organize large amounts of data in a concise and meaningful way. It is designed to look up information within the database, known also as a *query*, formatted in the computer language [[Structured Query Language|SQL]]. You will interact with the program via a screen which only has text called a terminal. Many queries have already been written in SQL for common use. For directions on how to use one of these previously written queries please visit the [[How to Use Prewritten Queries]] page.
