The class period. A measurement of time through the school day.  Period 11 stands in for Advisory. An empty value means that none was specified. Also referred to as period pulled and is optional in the PulledTime Table. Period 0 in this table stands for an unidentified period. Any other table this value appears is mandatory to include and should not be 0 (not database enforced). 

This is a whole number. (Unsigned integer)
