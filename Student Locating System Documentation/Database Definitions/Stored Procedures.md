Stored Procedures are SQL code that is stored in the database to be executed. To make the code run contained in the procedure you type in the CALL keyword and the procedure's name followed by a set of parathesis. Some procedures take in inputs to be used in the code that is stored. You enter these inputs in between the parathesis separating each with a comma. A comma is not necessary if there is only one input. 

Remember to put anything that is text like a name in between two apostrophes as if they were quotations. Ex. 'A Student's Name'
