A database is a structured collection of information or ==data== stored electronically on a computer system. It allows for efficient storage, retrieval, and management of information.

Databases are comprised of *tables*. Database Tables are like a spreadsheet in Excel. They are self contained but have links to other tables within the database; much like if there was a link in a spreadsheet connecting it to another in the same workbook (Excel file). They are linked in this manor such that information about related things can be found. For example, a student's name might link a class period with a certain teacher to the [[Student Table]] so that information just about that student can be found and not written down each time the student is referenced.
