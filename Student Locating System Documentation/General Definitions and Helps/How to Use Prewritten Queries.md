The database software mySQL allows you and others to store SQL code that is run often in the database. It allows you to give it a name so that you don't have to type all of it out again and again. MySQL also allows you to decide what information you want to look up in the database each time code is run. This means you can type in the student you want to look up with some SQL code instead of finding where the student's name belongs in the code each time. In short, these prewritten queries allow you to do what you want in the database much faster. 

For instructions on how to use these prewritten queries click on the Stored Procedures page below. This is also what these prewritten queries are called.
